Complete Setup Guide
📦 What You Have & What Each File Does

You downloaded three types of files. Here is exactly what each one is for:

1 — The 15 Standings iFrame Files

Files named like standings-basketball.html standings-soccer_i.html etc.

These are the live standings tables that show up on your Sidearm sport pages. Each one is a mini webpage that Sidearm will display inside a box (iFrame) on the relevant sport page. You upload these to GitHub Pages (free hosting) so they have a public URL. Then you paste that URL into Sidearm's iFrame tool on each sport page.

Right now they show placeholder "Team 1, Team 2…" rows. Once you connect Google Sheets (Phase 3 below) they will automatically pull in real team names and scores and refresh every 60 seconds.

2 — The 15 CSV Template Files

Files named like Basketball.csv SoccerI.csv etc. inside the csv_templates folder.

These are the starter data files for your Google Sheet. Instead of building your spreadsheet from scratch, you import these directly into Google Sheets — one per tab. Each one already has the correct column headers (Rank, Team Name, W, L, PF, PA, Streak, Notes) and 12 blank team rows ready to fill in. You do not need to set up any columns manually.

3 — This Setup Guide

The file you are reading right now. Keep it open and follow each phase below in order.

💡 You only need to do this setup once. After everything is connected, updating standings for the rest of the season takes about 2 minutes per game night — just open the Google Sheet and change some numbers.
Phase 1 of 4
1
Build Your Google Sheet

This is your central standings database. You will update it after every game night and it will automatically push to the website.

  1. 1
    Go to sheets.google.com and click the big + to create a new blank spreadsheet.
  2. 2
    Click the title at the top (it says "Untitled spreadsheet") and rename it: Royals Intramurals 2026/27 Standings
  3. 3
    Create 15 tabs — one per sport. Right-click the first tab at the bottom of the screen → Rename → type the first sport name. Then click the + button to add a new tab and repeat.
    The tab names must be spelled exactly as listed in the reference table at the bottom of this guide.
  4. 4
    Import the CSV files into each tab. Here is how:
    1. Click the Basketball tab to make it active
    2. Go to File → Import
    3. Click Upload and drag in the file Basketball.csv from your csv_templates folder
    4. Under "Import location" select Replace current sheet
    5. Click Import data
    6. Repeat for every tab using the matching CSV file
✅ After this step each tab will have the correct headers in Row 1 and 12 blank team rows below it. The column order is: A=Rank · B=Team Name · C=W · D=L · E=PF · F=PA · G=Streak · H=Notes
💡 You can now fill in the team names in column B for any sport that already has registered teams. Leave the W and L columns as 0 until games start.
Phase 2 of 4
2
Host the Standings Files on GitHub Pages (Free)

The 15 standings HTML files need to live at a public URL so Sidearm can embed them. GitHub Pages is free and takes about 5 minutes to set up.

  1. 1
    Go to github.com and create a free account if you don't have one.
  2. 2
    Click the + in the top right → New repository.
    Name it: royals-intramurals-standings
    Set it to Public. Click Create repository.
  3. 3
    On the next screen click uploading an existing file.
    Drag and drop all 15 standings-[sport].html files into the upload area.
    Scroll down and click Commit changes.
  4. 4
    Click Settings (top of the repo page) → scroll down to Pages in the left sidebar.
    Under "Source" select Deploy from a branch → choose main → click Save.
  5. 5
    Wait about 2 minutes then refresh the Settings → Pages page. You will see a green box that says:
    Your site is live at https://yourusername.github.io/royals-intramurals-standings/
    Your basketball standings file is now live at:
    https://yourusername.github.io/royals-intramurals-standings/standings-basketball.html
✅ All 15 files now have public URLs. Write them down or keep this tab open for Phase 3.
Phase 3 of 4
3
Connect Google Sheets to Each Standings File

This is the step that makes standings auto-update from the Sheet. Do this once per sport.

Part A — Get your Sheet ID (one step, same for all 15 sports)

  1. 1
    Open your Google Sheet and look at the URL in your browser address bar.
  2. 2
    Copy the long random string between /d/ and /edit — that is your Sheet ID. It looks like: 1aBcDeFgHiJkLmNoPqRsTuVwXyZ
  3. 3
    Click Share (top right) → set General access to Anyone with the link → Viewer → Done. This is required for the standings to load publicly.
✅ You only need one Sheet ID for all 15 sports — it's the same spreadsheet. The tab name is the only thing that changes per sport.

Part B — Add your Sheet ID and Tab Name to each standings file

The files no longer need a published CSV URL. Instead they use your Sheet ID and tab name directly — which is simpler and works without any proxy.

Step 1 — Find your Sheet ID

Open your Google Sheet. Look at the URL in your browser:

https://docs.google.com/spreadsheets/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ/edit

The highlighted part between /d/ and /edit is your Sheet ID. Copy it.

Step 2 — Make sure the sheet is shared publicly

  1. Click Share (top right of Google Sheets)
  2. Under "General access" change it to Anyone with the link
  3. Make sure it says Viewer (not Editor)
  4. Click Done
⚠️ The sheet must be set to "Anyone with the link" for the standings to load. It does not need to be published — just shared as a viewer link.

Step 3 — Edit each standings file on GitHub

  1. Go to your GitHub repository
  2. Click standings-basketball.html
  3. Click the pencil icon (Edit this file)
  4. Press Ctrl+F and search for SHEET_ID = ''
  5. Paste your Sheet ID between the quotes:
    const SHEET_ID = '1aBcDeFgHiJkLmNoPqRsTuVwXyZ';
  6. On the next line change the tab name:
    const SHEET_TAB = 'Basketball';
  7. Scroll down and click Commit changes
  8. Repeat for all 15 files — the SHEET_ID is the same for all of them, only the SHEET_TAB changes each time
💡 The Sheet ID is identical for all 15 files — it's the same Google Sheet. Only the tab name (SHEET_TAB) changes. So once you have the ID, it's a quick copy-paste job across all 15 files right in GitHub's editor.
✅ Standings are now live and auto-updating. Open your basketball standings URL in a browser — it should show your team names within a few seconds.
Phase 4 of 4
4
Embed Each Standings File into Sidearm

Now you place each standings iFrame inside the correct Sidearm sport page. Do this once per sport.

  1. 1
    In Sidearm go to the Basketball sport file and open the page editor.
  2. 2
    Click the iFrame button in the editor toolbar.
  3. 3
    Enter these settings:
    URL: https://yourusername.github.io/royals-intramurals-standings/standings-basketball.html
    Width: 100%
    Height: 680
    Scrolling: Auto
  4. 4
    Click OK or Insert. Save the sport page. The standings table will now appear embedded on the page.
  5. 5
    Repeat for all 15 sport pages using the matching standings URL for each.
💡 If the table gets cut off increase the height. For 12 teams 680px works well. For fewer teams you can reduce it to 500px.
✅ Setup complete. The iFrame is live on Sidearm and pulling from Google Sheets automatically.
🏆 Updating Standings During the Season

After every game night this is all you need to do — no Sidearm login, no file uploads, no coding:

  1. 1
    Open the Google Sheet on any device (phone, laptop, tablet).
  2. 2
    Click the tab for the sport that played (e.g. Basketball).
  3. 3
    Find the teams that played. Update their W (column C) and L (column D) numbers.
  4. 4
    Update the Streak column (column G). This is a running string of results — just add a W or L to the end.
    Example: if a team's streak was WWLL and they just won, change it to WWLLW.
    The website automatically reads the last character for the current streak and the last 5 characters for the coloured dots.
  5. 5
    Save. The Sidearm website updates automatically within 60 seconds. No further action needed.
✅ Anyone you share the Google Sheet with (give Edit access via the Share button) can update standings — great for having a student volunteer manage it on game nights.
